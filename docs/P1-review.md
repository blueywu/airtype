# AirType P1：独立输入服务、按钮映射与本地记录

原先只能在一个全局输入服务中二选一，现在可同时配置 Typeless 和 Codex 听写，用不同遥控器按钮调用。新装默认启用 Typeless（Right Cmd）；Codex 需先录制与宿主一致的快捷键，再勾选启用。已有服务及快捷键会迁移保留，已有豆包/微信配置不会被隐藏或删除。

## 行为

- 输入服务以勾选列表管理；豆包、微信在“添加输入服务”中添加，不下载应用。服务选择不切换系统键盘输入法。
- 每项服务独立录制快捷键，保留左右修饰键；相同及会抢先触发的修饰键前缀组合会提示冲突。开始听写后禁止改写当前快捷键。
- 按钮映射保留常用预设与直接录制入口，包含语音键；新绑定只提供已启用且配置完整的服务。停用服务保留原映射并明确标注，执行时拒绝调用。
- 普通按钮的服务动作复用原有语音会话与遥控器音频机制。语音键继续支持短按切换、按住松开结束；X6 延迟 HID 边沿不重复关闭刚切换的服务。
- 切换时发送旧服务的停止键并确认 CoreAudio 输入停止，再启动下一项。等待失败、焦点变化、目标被停用或遥控器断开时取消，快速重复请求不叠加。
- Codex 仅在其应用位于前台时启动/发送停止键；离开前台后无法安全停止时，提示回到 Codex 手动结束，不把快捷键发往其他应用。此判断检查应用 Bundle ID，不读取窗口标题或文字焦点。
- 按钮调用优先使用发出动作的那只遥控器；普通键的释放沿使用按下时捕获的映射。停用映射或断开设备时释放按住的键。
- 菜单栏换为确认过的纯声波模板图；菜单仍为设置和退出。App 大图标留待后续设计。

## 本地记录

默认关闭，可在“本地记录”开启、查看最近记录、导出 JSON、清空。关闭后停止新增，保留历史。记录层接入真实会话流程，图表不在本次范围内。

保存位置：`~/Library/Application Support/vRemote/Usage/sessions-v1.json`。保留原内部命名空间，以延续偏好与应用身份；目录权限 0700，文件权限 0600。

保存字段：会话 ID、尝试/确认开始/结束的 UTC 时间、听写时长、输入服务、按钮/键盘来源、动作、开始派发快捷键前的前台应用名称与 Bundle ID、结束结果。等待切换后重新采集前台应用。使用单调时钟计算时长；崩溃后开放记录标记中断，不猜测结束时间或累计时长。

不保存录音、识别文字、窗口标题、网页地址、剪贴板内容；不上传。启动失败不生成成功时长，重复音频回调不生成重复会话。关闭统计与清空均持久化，损坏文件会提示并保留原文件。

应用归因是“开始听写时所在应用”，不是最终文字插入位置；时长包含停顿。后台兼容音频常驻不会自行产生记录。只记录 AirType 观察到快捷键/按钮触发并确认的会话，无法从过去的调试日志回填。

## 验证与重现

在本地分支 `codex/voice-actions` 开发，基于 `main` 的 `3b7802f`；本次不合并 main、不上传 GitHub、不替换 `/Applications` 内应用或驱动。

```sh
Scripts/review-p1.sh /absolute/path/to/review-output
```

脚本构建 Debug/Release，运行四组测试，创建工作区中的隔离界面测试包，再捕获 13 个原生界面状态。测试包不会初始化 AppController、蓝牙、音频管线或全局按键监听；配置使用独立 UserDefaults suite，统计位于临时目录，结束后清理。截图进程通过 sandbox-exec 禁止网络。系统窗口截取不可用时自动保存原生视图位图；逐图方式记在 ui-results.json。

四组测试：服务配置/迁移/路由/记录，已有语音会话状态机，快捷键录制与事件序列，音频启停及真实 HAL 静音缓冲回归。测试使用模拟宿主状态，不向 Typeless/Codex 发送按键；音频测试不更改默认输入/输出设备。

截图覆盖：默认服务列表、双服务启用、添加服务、等待录制、Right Cmd 录制结果、独立按钮映射、自定义按钮录制、停用服务保留映射、Codex 前台保护、切换停止失败、本地记录关闭、模拟记录列表、未配置服务启用校验。

截图展示真实 SwiftUI 控件；设备连接和记录是明确标记的测试数据，Codex 示例快捷键仅用于隔离场景，不自动写入用户的 Codex 设置。这些结果不代替真实遥控器与宿主的语音转文字验收。CoreAudio 输入活动能确认宿主开麦，不能直接证明宿主进入听写或文字最终上屏。
